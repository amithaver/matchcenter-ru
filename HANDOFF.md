Ты продолжаешь проект футбольного портала. Ниже полный контекст: ничего не переспрашивай про стек и историю — всё здесь.

## 1. Что это
Футбольный сайт-справочник (матчи, лиги, страны, команды, таблицы, новости) под рынок Украины/России. **Без ставок и коэффициентов.** Цель — уникальные страницы под редкие запросы (включая экзотические страны: Куба, Никарагуа обязательны), которых нет у конкурентов.

## 3. Технические решения (не менять без причины)
- Статический сайт: Node без зависимостей, SSR-шаблоны в `lib/view.mjs`, роутинг в `server.mjs`, данные в `data/store.json`
- Адреса только латиницей и зафиксированы: `/match/{home}-{away}-{YYYY-MM-DD}`, `/team/{slug}`, `/league/{slug}`, `/country/{slug}`, `/date/{YYYY-MM-DD}`
- Проверено: `Intl.DateTimeFormat` нельзя создавать на каждый вызов (было 1,67 с на страницу → 5 мс после кэша)
- CMS обязана быть расширяемой: блоки описываются в `cms/src/payload.config.ts` (массив `Blocks`)

## 5. Что осталось — по блокам
**CMS:** импорт данных в коллекции; кнопка «Опубликовать» → пересборка; русские подписи полей; превью; роли; сжатие картинок; бэкапы базы.
**Данные:** парсер Кубы; парсер Никарагуа; ежедневный автоимпорт по cron; резервный источник; live-счёт.
**SEO:** тексты на все топ-матчи (готово 60 из ~3 000); автоперелинковка; русские названия турниров; словарь команд; 301-редиректы.
**Фронтенд:** страницы лиг и команд; мобильная вёрстка; обложки на все матчи; слоты рекламы.
**Инфраструктура:** HTTPS (ждёт домен), бэкапы сервера, мониторинг.

## 6. Приоритеты этой сессии
1. **Логотипы и иконки** — своя генерация, максимально похожие по духу, но НЕ оригиналы:
   - формы на выбор: щит, ромб, круг, овал, флаг-вымпел; для лиг — кубок/шеврон/эмблема
   - единая система: палитра клуба, инициалы или символ, обводка, тень; 3 размера (16/32/64 px)
   - генерировать локально (SVG), без внешних сервисов и без чужих логотипов
   - приближение к оригиналу ~90% по смыслу (цвета, форма, стиль), но собственная графика
2. **Парсер максимального охвата**: все страны и лиги, которые можно собрать (ESPN + альтернативы + парсинг сайтов), все групповые этапы и кубки; новости — заголовки и тексты
3. Прочее — по остатку из раздела 5

## 7. Ограничения
- Никаких ставок, коэффициентов, букмекеров
- Всё видимое — по-русски; URL — латиница
- Продукт не зависит от ассистента: сбор, расчёты, отчётность и интерфейс работают своим кодом
- Не трогать прод `uaroutes` на сервере
- Домен — в самом конце, после всех работ
- Ответы: коротко, цифрами, без воды

## 9. Известные грабли
- Payload админка требует `serverFunction` в `RootLayout` — без него 500
- SQLite в production: нужны миграции (`npx payload migrate:create` + `npx payload migrate`)
- Все пакеты `@payloadcms/*` и `payload` — строго одной версии
- npm в песочнице ассистента может быть заблокирован — ставить на сервере по SSH
- PowerShell ломает пути с `[[...segments]]` — использовать `-LiteralPath`
