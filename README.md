# Футбол России — матч-центр РПЛ

Сайт-матч-центр на русском: расписание, результаты, дата и время матчей, анонсы и отчёты. С админкой, где тексты и матчи правятся вручную. Без ставок и букмекерской рекламы.

Сделан **без зависимостей**: только Node.js 20+ и стандартная библиотека. `npm install` не нужен.

## Запуск

```bash
node server.mjs
```

Открыть:

- сайт — http://127.0.0.1:3000
- админка — http://127.0.0.1:3000/admin

Пароль по умолчанию `admin123`. Задать свой:

```bash
# Windows PowerShell
$env:ADMIN_PASSWORD="длинный-пароль"; node server.mjs
# Linux/macOS
ADMIN_PASSWORD=длинный-пароль node server.mjs
```

Порт и адрес: `PORT` (по умолчанию 3000), `HOST` (по умолчанию 127.0.0.1).

## Что умеет

| Раздел | Что делает |
|---|---|
| Матчи | список, фильтр по дате, страница матча с датой, временем (МСК), стадионом, счётом, анонсом и отчётом |
| Команды | 16 команд РПЛ, страница команды со всеми её матчами |
| Новости | статьи и статические страницы (о сайте, контакты) |
| Админка | вход по паролю, CRUD матчей, текстов, команд и настроек |
| SEO | ЧПУ, title/description на каждой странице, canonical, Open Graph, `SportsEvent` + `BreadcrumbList` + `SportsTeam` JSON-LD, `sitemap.xml`, `robots.txt` |

## Структура

```
server.mjs        маршруты, авторизация, sitemap, robots, статика
lib/db.mjs        хранилище (JSON-файл), CRUD, демо-данные
lib/view.mjs      HTML-шаблоны (SSR), SEO-теги, JSON-LD
public/app.css    стили
public/favicon.svg
data/store.json   база (создаётся автоматически)
```

Хранилище — один JSON-файл, запись атомарная (через `.tmp` + `rename`). Этого достаточно до первых сотен матчей; при росте — замена `lib/db.mjs` на Postgres без изменения шаблонов.

## Демо-данные

При первом запуске создаются 16 команд РПЛ, 14 матчей (7–22 ноября 2026) и 3 материала. Даты, счёт и тексты — **демонстрационные**, их надо заменить реальными через админку. Чтобы сбросить: удалить `data/store.json` и перезапустить.

## Публикация

**Быстро показать (без хостинга).** Запустить локально и открыть наружу туннелем:

```bash
cloudflared tunnel --url http://127.0.0.1:3000
```

Получите публичную ссылку вида `https://что-то.trycloudflare.com` — её можно отправить кому угодно. Живёт, пока запущен компьютер.

**Постоянно.** Любой хостинг с Node.js:

- Render / Railway / Fly.io — команда запуска `node server.mjs`, переменная `PORT` подставляется автоматически;
- VPS: `node server.mjs` под systemd или PM2, перед ним nginx + HTTPS (Let's Encrypt).

После публикации обязательно указать реальный домен в **Админка → Настройки → Домен**: от него зависят canonical, sitemap и JSON-LD.

## Что дальше (по приоритету)

1. Заменить демо-данные на реальный фид (`football-data.org` free-тир или ESPN), нормализация в `lib/db.mjs`.
2. Перевести хранилище на Postgres/SQLite при росте числа матчей.
3. Добавить загрузку логотипов команд и картинок к новостям.
4. Подключить Яндекс.Метрику, отправить `sitemap.xml` в Яндекс.Вебмастер, привязать регион.
5. Автогенерация анонсов: шаблон + факты из базы, LLM только формулирует текст.

## Ограничения

- Нет регистрации пользователей и ролей — один пароль на всю админку.
- Нет загрузки файлов (логотипы/фото) — только текст.
- CSRF-защита минимальная (SameSite=Lax + проверка сессии); для публичного продакшена добавить токен формы.
- Демо-данные не являются официальными данными РПЛ.
