# Live Football — матч-центр мирового футбола

Сайт на русском: страны, дивизионы, расписание, результаты, турнирные таблицы, бомбардиры, таймлайн матча. С админкой. Без ставок и букмекерской рекламы.

Технологии: **Node.js 20+ без зависимостей** (только стандартная библиотека), SSR, JSON-хранилище с атомарной записью.

## Запуск

```bash
node scripts/import-espn.mjs   # собрать данные (один раз, ~50 секунд)
node server.mjs                # http://127.0.0.1:3000
```

Админка: http://127.0.0.1:3000/admin — пароль `admin123` (меняется через `ADMIN_PASSWORD`).

```bash
# Windows PowerShell
$env:ADMIN_PASSWORD="свой-пароль"; node server.mjs
# Linux/macOS
ADMIN_PASSWORD=свой-пароль node server.mjs
```

## Данные

`scripts/import-espn.mjs` собирает из открытого ESPN API:

- матчи за окно дат (`WINDOW` в скрипте) — счёт, статус, стадион, город;
- таймлайн: голы, карточки, автоголы, пенальти — минута, игрок, команда;
- турнирные таблицы (место, И/В/Н/П, голы, очки).

Охват: Англия, Испания, Уругвай, Колумбия, Венесуэла, Эквадор, Коста-Рика, Гондурас, Сальвадор, Гватемала — 12 стран, 12 лиг, 163 команды, 196 матчей, 10 таблиц.

**Куба и Никарагуа в ESPN отсутствуют** — данные по ним вносятся вручную (сейчас там демонстрационные матчи). Это как раз тот контент, которого нет у конкурентов.

Имена команд транслитерируются автоматически (словарь для топ-клубов + правила испанской транслитерации). Ошибки правятся в админке: Команды → Править.

## Страницы

| URL | Что отдаёт |
|---|---|
| `/` | ближайшие матчи, результаты, страны |
| `/countries` | все страны |
| `/country/:slug` | лиги страны, матчи, команды |
| `/league/:slug` | турнирная таблица, календарь, результаты, бомбардиры |
| `/match/:slug` | счёт, таймлайн, форма команд, история встреч, другие матчи дня |
| `/team/:slug` | все матчи команды, форма |
| `/date/YYYY-MM-DD` | все матчи дня |
| `/news`, `/news/:slug` | материалы и статические страницы |
| `/sitemap.xml`, `/robots.txt` | для поисковиков |

## SEO

- SSR, без клиентского JS — быстрый ответ и полный HTML для роботов.
- Уникальные `title`/`description` на каждой странице по формуле «сущность + дата + турнир».
- `canonical` на всех страницах, `robots: noindex` в админке.
- JSON-LD: `SportsEvent` (дата, место, участники), `BreadcrumbList`, `SportsTeam`, `SportsOrganization`, `WebSite`, `Article`.
- Внутренняя перелинковка: страна → лига → матч → команда → история встреч → таблица.
- `sitemap.xml` генерируется из базы (все лиги, команды, матчи, даты).
- `<html lang="ru">`, `geo.region: RU`, время в Europe/Moscow.

## Админка

- **Матчи** — создать/править/удалить, лига, дата, счёт, стадион, ход матча (строка = событие: `45'|Гол|home|Иванов`), анонс и отчёт текстом.
- **Страны и лиги** — добавить страну и лигу (для экзотики, которой нет в фиде).
- **Команды** — добавить/переименовать (правит транслитерацию).
- **Тексты** — новости и статические страницы.
- **Настройки** — название, домен, e-mail.

## Публикация

```bash
cloudflared tunnel --url http://127.0.0.1:3000   # быстрая публичная ссылка
```

Постоянно: Render / Railway / VPS (`node server.mjs`), затем домен в Настройках — от него зависят canonical и sitemap.

## Ограничения

- Один пароль на админку, без ролей и CSRF-токена формы.
- Нет загрузки изображений (логотипы/фото) — только текст.
- Парсер ESPN неофициальный: формат может измениться, данные требуют периодической пересборки.
- Куба/Никарагуа — ручной ввод, автоматического источника нет.
- Таблицы и матчи — срез на момент импорта, live-обновления пока нет.
